# PlanProof releases

Public installer + auto-update feed for **PlanProof**. The application source lives in a private repository; only the Windows installer and update metadata are published here.

## Install

Download the latest `PlanProof-Setup-<version>.exe` from the [Releases](https://github.com/TakeoffWorks/planproof-releases/releases) page and run it. The app updates itself automatically thereafter.
